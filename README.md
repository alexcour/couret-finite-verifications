# Public archive migration checks\n\nThis branch contains an original preparation script and workflow. The workflow retrieves two public Zenodo archives, validates their exact size and SHA256, selects the import closure of the advertised mathematical theorem, adds the current Lean module-system visibility and builds on pinned Lean 4.35.0-rc2 / Mathlib. Archived source files are not committed to this branch and do not acquire its MIT script licence. Original archive reuse notices retain their scope.\n\nThis is preparation, not a Palomar submission, peer review, priority claim or a whole-corpus build. Existing Lean receipts remain historical. New failures are retained in Actions and must be resolved before any success claim.\n
