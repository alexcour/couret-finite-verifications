# Singleton-overlap four-point square collisions and C4 × C4 subgroups

For any decidable abelian group, two four-point finite supports with one common point and identical full labelled ordered squares exist exactly when Z/4Z × Z/4Z embeds additively. The ambient group need not be cyclic or finite. No novelty assessment or independent human review is asserted.

This is a Palomar preparation snapshot. Compilation of earlier migration closures is not an official Comparator result. Package compilation, official checking and registration are separate stages.
