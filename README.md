# Two fixed cubic coefficients distinguish a cyclic four-point square fibre

For a four-point support in Z/nZ with n positive and its full labelled ordered square supplied, at most two fixed labelled coefficients of the ordered cube separate the complete four-point square fibre. Coefficient responses are exact integer values embedded in the reals; they are not binary answers. No query lower bound or runtime claim is asserted.

This is a Palomar preparation snapshot. Compilation of earlier migration closures is not an official Comparator result. Package compilation, official checking and registration are separate stages.
