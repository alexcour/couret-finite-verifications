# Decision factorization on the attained observation image

A decision function factors through the attained observation image exactly when it is constant on each observation fibre. This is a logical interface theorem; no runtime, parity-cost, optimal-query or Python implementation equivalence is asserted.

This is a Palomar preparation snapshot. Compilation of earlier migration closures is not an official Comparator result. Package compilation, official checking and registration are separate stages.
