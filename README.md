# Cyclic four-point square fibres and fixed membership reconstruction

For a four-point support in Z/nZ with n positive, the complete labelled ordered-square fibre has cardinality one, two or four. At most two fixed binary membership probes separate that fibre. The full square and its fibre are supplied; no computational runtime bound or adaptive query lower bound is asserted.

This is a Palomar preparation snapshot. Compilation of earlier migration closures is not an official Comparator result. Package compilation, official checking and registration are separate stages.
