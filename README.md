# Sharp six-letter saturation threshold modulo 30

For words in the unit-residue code modulo 30, six or more letters make full and proper subsequence-product supports coincide. The five-prime word 7,7,7,11,17, of product 64141, witnesses failure at length five. This is a finite-group combinatorial support theorem, with no general integer factorization algorithm or prime distribution claim.

This is a Palomar preparation snapshot. Compilation of earlier migration closures is not an official Comparator result. Package compilation, official checking and registration are separate stages.
