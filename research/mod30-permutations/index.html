Le noyau arithmétique

Nous étudions le groupe des unités de l'anneau des entiers modulo 30 :

G₃₀ = {1, 7, 11, 13, 17, 19, 23, 29}.

Pour chaque a de ce groupe, la règle Pₐ(x) = a × x (mod 30) est une permutation réversible. Elle ne crée ni ne détruit d'élément.

Ce qui est établi

Pour tout élément inversible a modulo 30, la multiplication par a est bijective. Son inverse est la multiplication par l'inverse de a modulo 30. La décomposition en cycles est calculée exactement dans ce groupe fini.

Ce qui reste à rechercher

Les extensions arithmétiques 30 → 210 → 2310 → … offrent une famille de problèmes de compatibilité et de passage à la limite. Cependant, une limite profinie de groupes finis est encore totalement discontinue : elle ne constitue pas à elle seule un continuum physique.

Question ouverte : sous quelles hypothèses un transport d'information défini sur des structures discrètes peut-il admettre une description continue dotée d'observables testables ? Aucun passage universel vers la physique n'est revendiqué ici.

Provenance et prudence

Cette page est une présentation pédagogique de propriétés classiques d'arithmétique modulaire, pas la déclaration d'une découverte, d'une validation expérimentale ou d'une preuve de l'hypothèse de Riemann. Les preuves, calculs, conjectures et résultats de programmation doivent toujours être distingués.

Sources publiques : vérifications finies et vision de recherche. L'application pédagogique et son code source sont proposés dans une branche de revue : aucune validation scientifique indépendante n'est sous-entendue.
