## Défauts reproduits et corrections proposées
| ID | Défaut source | Traitement |
|---|---|---|
| R01 | Après une mesure paire k=2, le défi accepte l'autre candidat et l'interface annonce une reconstruction unique. | Recalculer les candidats compatibles ; distinguer compatibilité et unicité ; permettre une mesure supplémentaire explicite. |
| R02 | Un champ measurements qui est un objet est ignoré au lieu d'être rejeté. | Valider tableau, mode, cardinal, mesures, conventions, support et décision. |
| R03 | Modifier allowed sans changer status laisse isCleanReplay=true. | Comparer les deux champs ; toujours conserver la décision recalculée. L'ancien moteur recalculait déjà allowed : ce défaut concerne le signalement de divergence, pas une autorisation forgée exécutée. |
| R04 | Le résultat d'import omet la position utilisée par l'interface. L'interface déduit aussi le mode du nombre de lectures et arrondit les lectures. | Restituer la position et le mode ; conserver le mode et la précision ; refuser explicitement un état hors de la capacité d'affichage avant mutation. |
| R05 | Une fibre vide est étiquetée DEJA_DETERMINE. | Distinguer OBSERVATIONS_INCOMPATIBLES et fibre singleton. |
| R06 | Un témoin STROBO dont les deux supports sont identiques est accepté. Métadonnées altérées et R prolongé passent aussi. | Vérifier supports distincts, taille de R et métadonnées recalculées. |
| R07 | La règle distance <= epsilon + 1e-12 admet y=0 dans C4 avec epsilon=1-5e-13, alors que la distance exacte est 1. | OUVERT : un traitement conservateur/certifié des frontières numériques doit être défini. Aucune certification numérique n'est ajoutée par ce correctif. |

Autres corrections de présentation : erreurs d'import rendues avec textContent ; suppression de la promesse de secret inaccessible et du terme « recalcul certifié » dans les interfaces modifiées.

## Limites avant intégration
- R07 reste ouvert ; ne pas promouvoir cette version en garantie exacte aux frontières.
- Les saisies vides/invalides dans l'interface nécessitent encore une politique explicite de blocage. L'ancien code peut convertir une valeur vide en zéro ou remplacer epsilon invalide par 0.1.
- Un R sans support est refusé par l'interface d'import, avec explication ; le cœur peut toujours en produire le diagnostic incompatible. Un affichage complet de telles observations est un lot distinct.
- Les fichiers autonomes recoh.html, iframe srcdoc et manifestes de paquet doivent être régénérés à partir de la version retenue avant déploiement. Ils ne sont pas implicitement mis à jour par ce correctif de source.
- Ne pas fusionner automatiquement cette proposition dans #69 ; relire les évolutions concurrentes.
- Ne pas présenter les corrections de source comme déjà appliquées sur WordPress.
