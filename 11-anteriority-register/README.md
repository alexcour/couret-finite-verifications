# Prior-art/status register — scope of public release v1.0.0

This register is deliberately limited to material actually present in the public release. It
is not a novelty opinion and does not list withheld research questions.

| public item | status/source context |
|---|---|
| `03`: local root counts and singular-series heuristic for `2k^2+2k+1` | Bateman–Horn heuristic applied to one irreducible quadratic; infinitude of prime values remains open |
| `03`: Pythagorean parametrisation and Gaussian-norm identity | classical |
| `05`: equidistribution among reduced residue classes | Dirichlet/PNT in arithmetic progressions, classical |
| `05`: residual Chebyshev-bias framework | Rubinstein–Sarnak (1994), conditional on GRH + linear independence |
| `09`: Parseval/orthogonality identities on finite abelian groups | standard finite Fourier analysis |
| `09`: annihilator of a subgroup and vanishing of non-trivial character sums on a subgroup | standard finite character theory |
| `09`: `E|Z_k|^2=1/k` for independent uniform unit phases | elementary expectation/orthogonality calculation |
| `09`: Pythagorean divisibility modulo 2,3,5 | elementary congruence calculation |

## Core references

- P. T. Bateman and R. A. Horn, “A heuristic asymptotic formula concerning the distribution
  of prime numbers”, *Mathematics of Computation* 16 (1962), 363–367.
- M. Rubinstein and P. Sarnak, “Chebyshev's bias”, *Experimental Mathematics* 3 (1994),
  173–197.
- A standard text on finite abelian harmonic analysis/characters may be used for the Parseval,
  annihilator, and subgroup character-sum identities; these identities are also proved directly
  in the folder README at the level needed by the supplied computations.

The G30 registry, HOL-01, and unresolved anteriority candidates are intentionally absent from
this public register.
